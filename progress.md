# 🍰 WHISKORA – Project Development Progress

### Whisk Your Imagination to Life.

**WHISKORA** is a web-based cake customization project designed to let users explore cake options and personalize their cakes through an interactive and visually appealing website.

---

## 📅 Day 1 – Project Initialization

### 🎯 Goal
Establish the project idea and create the initial website structure.

### ✅ Progress
- Finalized the initial concept of a cake customization website.
- Created the GitHub repository.
- Added the initial project README.
- Established the basic project folder structure.
- Created the initial `index.html` and `404.html` files.
- Started building the website's basic layout.

### 🚀 Next Steps
- Finalize the project name and branding.
- Improve the website's visual identity.
- Develop the cake customization interface.

**Status:** Initial Setup Completed.

## 📅 Day 2 – Introducing WHISKORA

### 🎯 Goal
Give the project its official identity and establish its visual direction.

### ✅ Progress
- Finalized the official project name: **WHISKORA**.
- Established the tagline: **"Whisk Your Imagination to Life."**
- Defined a premium bakery-inspired visual identity.

## 📅 Day 3 – Building the WHISKORA Experience

### 🎯 Goal
Improve the website interface and introduce the cake customization experience.

### ✅ Progress

#### 1. Homepage Improvements
- Refined the homepage layout and visual presentation.
- Improved the overall design consistency.
- Maintained WHISKORA's premium bakery-inspired theme.

#### 2. Cake Customization Interface
- Introduced an interactive cake customization section.
- Added flavour options:
  - Vanilla
  - Eggless Vanilla
  - Chocolate
  - Red Velvet
  - Butterscotch
- Added cake shape options:
  - Round
  - Heart
  - Square
- Added cake size options:
  - 500g
  - 1kg
  - 2kg
- Implemented selection highlights for chosen options.
- Added dynamic price calculation based on cake size.
- Introduced a basic visual cake preview using CSS.
- Added a customization summary displaying the selected options.

#### 3. Custom 404 Error Page
- Created a dedicated `404.html` page.
- Designed the error page to match WHISKORA's branding.
- Added a friendly bakery-themed error message.
- Included a button to navigate back to the homepage.

### 💡 Key Takeaway
The project is gradually moving from a basic website structure towards an interactive cake customization platform.

**Status:** Homepage Refined | Customization Interface Added | Custom 404 Page Created.
